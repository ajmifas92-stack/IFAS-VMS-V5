# IFAS VMS V3 Visual/Icon Package

This package updates the current source build with:
- IFAS VMS client application icon.
- Supplier License Creator application icon.
- Shared IFAS icon assets for Server, Config, License Manager, Log Viewer and Updater.
- Supplier-only License Creator installation script.
- Standard client/server installer no longer copies the supplier License Manager.
- Existing dark IFAS VMS dashboard/client UI remains the current implemented UI foundation.

Important: the visual reference image shown during the conversation is a UI design reference, not a claim that every screen is fully implemented. The current client contains the dashboard shell, camera list, RTSP live-view foundation, recording, snapshot and ONVIF discovery foundation. Full multi-camera recording orchestration, playback/timeline, complete PTZ, online activation service and production installer still require Windows build and real-device validation.
