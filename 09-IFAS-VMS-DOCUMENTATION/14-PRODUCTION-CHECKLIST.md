# Production Deployment Checklist

## Build
- [ ] Release build completed
- [ ] Automated tests passed
- [ ] No development secrets
- [ ] Dependencies reviewed

## Security
- [ ] HTTPS/TLS configured
- [ ] Strong secrets installed
- [ ] Private signing key protected
- [ ] Public license verification key configured
- [ ] Firewall configured
- [ ] Least-privilege accounts configured
- [ ] Audit logging enabled

## Licensing
- [ ] Correct license issued
- [ ] Expiry verified
- [ ] User limit verified
- [ ] Camera limit verified
- [ ] Features verified

## Operations
- [ ] Backup configured
- [ ] Restore tested
- [ ] Update process tested
- [ ] Monitoring/logging configured
- [ ] Recovery procedure documented
