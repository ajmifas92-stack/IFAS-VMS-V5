# Backup and Restore

Back up:

- Database
- Application configuration
- License records
- Audit data
- Important system metadata

Do not casually back up private signing keys into ordinary customer backups. Protect sensitive keys separately.

## Suggested practice

Maintain:
- Regular automated backups
- At least one protected/offline copy
- Restore testing
- Backup retention policy
- Documented recovery procedure

A backup is useful only if restoration has been tested.
