# IFAS VMS - Product Overview

IFAS VMS is a Windows-based Video Management System architecture containing:

1. IFAS VMS Server
2. IFAS VMS Client
3. IFAS License Manager
4. IFAS VMS Database package
5. IFAS VMS Shared package
6. IFAS VMS Security package
7. IFAS VMS Installer
8. IFAS VMS Updater

## Main capabilities

- User authentication
- Role-based permissions
- IP camera management
- RTSP/ONVIF-oriented camera support
- Live monitoring foundation
- Recording/playback foundation
- License limits
- Audit logging
- Secure update foundation

## Important

The current project is a development foundation. Production deployment requires testing, certificate management, secure secret storage, monitoring, backup procedures, signed releases and security review.
