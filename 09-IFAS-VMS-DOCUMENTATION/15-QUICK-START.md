# IFAS VMS Quick Start

1. Build the solution on a Windows PC.
2. Start IFAS VMS Server.
3. Initialize/configure the database.
4. Configure HTTPS and security secrets.
5. Use License Manager to issue a valid license.
6. Install the license on the Server.
7. Start IFAS VMS Client.
8. Connect to the Server.
9. Log in.
10. Add cameras.
11. Test live monitoring.
12. Configure users and permissions.
13. Test backup and restore.
14. Test updater/rollback before production.
