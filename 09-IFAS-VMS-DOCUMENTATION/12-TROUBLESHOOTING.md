# Troubleshooting

## Server does not start

Check:
- .NET runtime/SDK
- Configuration syntax
- Port availability
- Database permissions
- HTTPS certificate
- Logs

## Client cannot connect

Check:
- Server URL
- DNS/IP
- Firewall
- HTTPS certificate
- Server status
- Network connectivity

## Camera offline

Check:
- Camera IP
- Port
- Username/password
- RTSP/ONVIF configuration
- Network routing
- Camera stream availability

## License rejected

Check:
- License file integrity
- Signature
- Expiry date
- Revocation state
- Server public verification key
- User/camera limits

Do not disable security checks as a production workaround.
