# Updater Release Checklist

- [ ] Build Release packages.
- [ ] Run automated tests.
- [ ] Create update ZIP.
- [ ] Generate SHA-256 hash.
- [ ] Digitally sign update package/manifest.
- [ ] Publish manifest over HTTPS.
- [ ] Test clean installation.
- [ ] Test upgrade.
- [ ] Test failed update and rollback.
- [ ] Test interrupted download.
- [ ] Verify configuration and license/security components.
