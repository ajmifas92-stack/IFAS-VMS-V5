# 05-IFAS-VMS-SHARED

Shared contracts, DTOs, constants and utility types used by IFAS VMS modules.

Purpose:
- Keep common API contracts in one place.
- Prevent duplicated models between Server, Client and License Manager.
- Provide stable enums/constants for communication.
- Keep shared code free from UI and database-specific dependencies.

Target:
- .NET 8
- C#
